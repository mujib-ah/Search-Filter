# Search Filter

A simple Search Filter project built with HTML, CSS and JavaScript.

## Features

- Search users by name
- Real-time filtering
- Case-insensitive search
- Simple and responsive design
- Instant results while typing

## Technologies

- HTML
- CSS
- JavaScript

## How It Works

The user types a name into the search input.

JavaScript listens for the input event and checks each user name.

If the name matches the search text, the user remains visible.

If there is no match, the user is hidden.
